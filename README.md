# AFL & AFLW Fixture Calendars 📅
### Free 2027 AFL and 2026 AFLW Fixture Calendars for All 18 Teams

Never miss a game! Subscribe to live **[AFL (Australian Football League)](https://www.afl.com.au)** and **AFLW** fixture calendars for all 18 clubs — automatically updated every hour so you always have the latest match times and venues in your calendar.

> ⚠️ This is **AFL & AFLW — Australian Rules Football**, not American football (NFL).

## 🗓️ What is this?

This project generates `.ics` calendar subscription feeds for every club's season fixtures, for both the men's AFL (2027) and the AFLW (2026). Once you subscribe, your calendar app automatically stays up to date — no manual imports needed.

- ✅ All 18 AFL clubs (2027 season) and all 18 AFLW clubs (2026 season)
- ✅ Match times converted to **your local timezone** automatically
- ✅ Venue / location included for every game
- ✅ Finals fixtures included as soon as they are announced, even with unconfirmed participants
- ✅ Updated every hour from [fixturedownload.com](https://fixturedownload.com/sport/aussie-rules)
- ✅ Works with Apple Calendar, Google Calendar, Outlook, and any app that supports `.ics` subscriptions

## 📱 Setup instructions by app

### Apple Calendar (iPhone, iPad, Mac)
1. Open the **Calendar** app → tap **Calendars** at the bottom
2. Tap **Add Calendar** → **Add Subscription Calendar**
3. Paste your team's URL → tap **Subscribe**
4. Set auto-refresh to **Every Hour**
5. Tap **Add** to confirm

### Google Calendar
1. Open [Google Calendar](https://calendar.google.com) on desktop
2. Click the **+** next to "Other calendars" in the left sidebar
3. Select **From URL**
4. Paste your team's URL → click **Add Calendar**
5. Note: Google Calendar refreshes subscriptions roughly every 24 hours

### Outlook (Desktop or Web)
1. Open Outlook Calendar
2. Click **Add Calendar** → **Subscribe from web**
3. Paste your team's URL → click **Import**

### Subscribing vs importing
**Subscribing** (recommended) keeps your calendar in sync automatically — when fixture times or venues change, your calendar updates itself. **Importing** a one-off `.ics` file creates a static snapshot that never changes. All URLs above are subscription URLs.

## 🌍 Timezones

All match times are stored in **UTC** in the calendar feed. Your calendar app will automatically convert them to your local timezone — whether you're watching from Melbourne, London, New York, or anywhere else in the world.

Event durations (AFL: 150 minutes; AFLW: 120 minutes) are **calendar scheduling estimates only**, not actual match lengths. Actual match lengths vary and are not tracked by this feed.

## ❓ Frequently Asked Questions

**Is this free?**
Yes, completely free. No sign-up required.

**How often is it updated?**
The feeds are automatically refreshed every hour via GitHub Actions.

**Will it show finals fixtures?**
Yes. Finals fixtures appear as soon as fixturedownload.com lists them — including fixtures where the participants are still placeholders (e.g. "Winner of PF1 v Winner of PF2"). Two-unknown-participant fixtures appear only in the All Teams feed; once participants are resolved to clubs, the fixture also appears in the relevant club feeds on the next successful build.

**What about season rollover?**
Each season is a separate set of events with distinct identities (UIDs include the competition and season). When the feeds advance to a new season, your subscribed calendar gains the new season's fixtures; calendar clients differ in how they treat events from the previous season, and this project does not cancel or rewrite old fixtures. Check your calendar app's documentation for how it handles subscription refreshes, and remove stale previous-season events if your app does not.

**Do AFL and AFLW calendars overlap?**
No. AFL 2027 and AFLW 2026 are separate competitions with separate feeds and separate All Teams aggregates. There is no combined men's + women's feed.

**Does it work outside Australia?**
Yes! Times automatically display in your local timezone.

**What's the difference between AFL and NFL?**
[AFL](https://www.afl.com.au) is **Australian Rules Football** — an entirely different sport played on an oval field, popular in Australia. NFL is American Football. These calendars are for AFL and AFLW only.

## 🔧 How it works (technical)

- A **GitHub Actions** workflow runs every hour on the default branch and runs the test suite, then fetches the full-season fixture JSON for **AFL 2027** (`afl-2027`) and **AFLW 2026** (`aflw-2026`) from [fixturedownload.com](https://fixturedownload.com/sport/aussie-rules)
- Both sources are **validated before anything is written**: schema, unique match identifiers, season-appropriate dates, known club labels or recognized finals placeholders, and consistent scores. If either source fails validation, the run fails and the previously published calendars remain unchanged.
- Club and aggregate calendars are **derived from the validated full-fixture dataset** (not by stitching per-club output together), so finals with unknown participants are included in the All Teams feed
- Output is staged and validated (structure, UID uniqueness, 75-octet line folding) before being copied into `docs/`
- Generated files are committed to the `docs/` folder and served via **GitHub Pages** (source: `main` branch, `/docs` folder)
- Each event has a stable UID (`<competition>-<season>-<MatchNumber>@afl-calendar-feeds`) so updates replace existing calendar entries rather than creating duplicates. UIDs survive reschedules and participant changes as long as the source match identifier is unchanged.

## 📁 Repo structure

```
.github/workflows/update-calendars.yml   # hourly scheduled workflow (tests + build, main-only publish)
src/build.js                             # staged all-or-nothing build entry point
src/config/competitions.js               # per-competition config: season, source, duration estimate
src/config/clubs.js                      # canonical club metadata + upstream labels
src/lib/fixtures.js                      # fetch + validation/normalization
src/lib/ics.js                           # RFC 5545 escaping, UTF-8-aware folding, rendering
src/lib/build-competition.js             # club + aggregate calendar derivation
src/lib/validate-output.js               # staged-output validation gate
test/                                    # node:test unit tests (no framework)
docs/afl/<team>.ics                      # generated AFL 2027 club feeds
docs/afl/all-teams.ics                   # generated AFL 2027 aggregate
docs/aflw/<team>.ics                     # generated AFLW 2026 club feeds
docs/aflw/all-teams.ics                  # generated AFLW 2026 aggregate
docs/index.html                          # GitHub Pages landing page
```

Seasons are explicit configuration in `src/config/competitions.js` — they are never derived from the current date, and there is no automatic fallback to a newer season.
